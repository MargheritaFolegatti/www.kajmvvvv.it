# Kajmvvv.it

Sito vetrina per **Kajmvvv**, il laboratorio di Alice: portachiavi in resina fatti a mano, con le iniziali, i colori e le decorazioni scelti da chi li ordina.

Sito: [www.kajmvvvv.it](https://margheritafolegatti.github.io/www.kajmvvvv.it/)

### ✨ Cosa c'è:

- Vetrina dei portachiavi disponibili, ognuno con prezzo e richiesta via email
- Configuratore in 5 passi (lettera, colore della resina, decorazione, cordino, dati) con anteprima dal vivo e prezzo aggiornato
- Invio dell'ordine via Instagram o email, con il riepilogo già pronto
- Come nasce un portachiavi, chi è Alice e il calendario dei mercatini

### 👩‍💻 Fatto con:

- HTML, CSS e JavaScript, senza framework
- Font Awesome per le icone
